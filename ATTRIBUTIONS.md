# Attributions

PSL to TSM includes no third-party code.

## Works with

- **Profession Shopping List** by Slackluster: required. PSL to TSM reads
  its TSM search string and shopping list through its public API
  (`GetTSMSearchString()` and `GetMerchantShoppingList()`), or for older PSL
  releases, its saved list of tracked recipes. The TSM tab is added to PSL's
  tracking window with Slackluster's OK. No PSL code is included.
  https://www.curseforge.com/wow/addons/profession-shopping-list
- **TradeSkillMaster**: the search string is written in TSM's search
  syntax. PSL to TSM never calls TSM itself.
  https://www.tradeskillmaster.com/
